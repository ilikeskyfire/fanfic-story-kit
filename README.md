# fanfic-story-kit

为米哈游旗下作品（绝区零、崩坏：星穹铁道等）的同人创作提供背景故事、世界观设定与剧情主线参考的 Story Kit。纯静态、离线可用、持续更新。

## 使用方式

1. 直接双击根目录的 `index.html` 打开作品列表。
2. 进入某部作品后可浏览首页、主线剧情、角色、时间线、世界观与搜索。
3. 页面为纯静态、离线可用，数据通过 `data.js` 以 `<script>` 方式加载，**不需要本地服务器**，支持 `file://` 直接打开。

### 亮 / 暗主题

- 导航页右上角、作品页桌面顶栏与移动端顶栏都有切换按钮（☀ / ☾）。
- 默认跟随系统 `prefers-color-scheme`；手动选择后写入 `localStorage` 的 `storykit-theme`，全站共享、刷新不丢失。
- `<head>` 内联脚本在样式表加载前设置 `data-theme`，避免首屏闪烁。

### 快捷键与交互

- 剧情页支持整段对话复制；时间线、角色、世界观可交叉跳转。
- 搜索框支持剧情 / 角色 / 台词关键词（快捷键 `/`）。

## 目录结构

```
.
├── index.html              # 作品总入口（hub）
├── works.js                # 作品注册表
├── _shared/                # 共用的样式与查看器脚本
│   ├── viewer.css          # 主题 token + 亮/暗配色
│   └── viewer.js           # 路由、渲染、搜索、主题切换
├── docs/
│   ├── content-format.md   # Markdown 内容格式规范
│   └── add-work.md         # 新增一部作品的步骤
├── 绝区零/
│   ├── index.html          # 作品入口
│   ├── work.json           # 作品元信息
│   ├── build.py            # Markdown → data.js 构建脚本
│   ├── data.js             # 生成产物（不要手改）
│   └── content/
│       ├── 00-worldview.md
│       ├── 01-timeline.md
│       ├── 10-story/       # 每章一个 Markdown
│       └── 20-characters/  # 每个角色一个 Markdown
└── 星穹铁道/                # 结构同绝区零
```

## 编辑与构建

Markdown 是唯一内容源。修改某作品的 `content/` 后，在该作品目录运行：

```bash
cd 绝区零        # 或 cd 星穹铁道
python3 build.py
```

脚本会重新生成 `data.js`，并输出章节、角色、时间线与世界观数量，以及对话行数。格式规范见 [docs/content-format.md](docs/content-format.md)，新增作品见 [docs/add-work.md](docs/add-work.md)。
