# fanfic-story-kit

为原神、崩坏：星穹铁道、绝区零同人创作提供背景故事、世界观设定与剧情主线参考的 Story Kit。持续更新。

## 当前收录

- 绝区零：第一季（1.0–1.7）→ 第二季（2.0–2.8）→ 第三季（3.0–3.3），含主线剧情、关键场景对话、角色、时间线与世界观词条。

## 使用方式

1. 直接双击根目录的 `index.html` 打开作品列表。
2. 进入「绝区零」后可浏览首页、主线剧情、角色、时间线、世界观与搜索。
3. 页面为纯静态、离线可用，数据通过 `data.js` 以 `<script>` 方式加载，不需要本地服务器。

## 目录结构

```
.
├── index.html              # 作品总入口
├── works.js                # 作品注册表
├── _shared/                # 共用的样式与查看器脚本
│   ├── viewer.css
│   └── viewer.js
└── 绝区零/
    ├── index.html          # 作品入口
    ├── work.json           # 作品元信息
    ├── build.py            # Markdown → data.js 构建脚本
    ├── data.js             # 生成产物（不要手改）
    └── content/
        ├── 00-worldview.md
        ├── 01-timeline.md
        ├── 10-story/       # 每章一个 Markdown
        └── 20-characters/  # 每个角色一个 Markdown
```

## 编辑与构建

Markdown 是唯一内容源。修改 `绝区零/content/` 后运行：

```bash
cd 绝区零
python3 build.py
```

脚本会重新生成 `data.js`，并输出章节、角色、时间线与世界观数量，以及对话行数。
