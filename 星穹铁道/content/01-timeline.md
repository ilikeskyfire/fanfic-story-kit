# 崩坏：星穹铁道 时间线

## 远古星神与命途起源

- 时代: 远古
- 日期: 不明
- 章节: 背景
- 次要: true

星神在漫长宇宙史中相继出现，各自践行的命途由此成为影响文明的力量。存护、智识、开拓、丰饶等星神及其追随者，在不同纪元塑造了星际格局。

多数星神的确切诞生年代和先后顺序并未完整公开，现存记载也夹杂神话与各派系叙述，不宜据此建立精确年表。

## 星核的出现与蔓延

- 时代: 星核时代
- 日期: 不明
- 章节: 背景
- 次要: false

星核开始在多个世界造成灾害，并被称为「万界之癌」。一些世界的星轨因此中断，文明则在裂界、环境异变或战争中衰败。

星核的确切起源和首次出现时间不明，其与纳努克及反物质军团的关系也需按具体事件区分。

## 星穹列车与阿基维利的开拓

- 时代: 远古
- 日期: 不明
- 章节: 背景
- 次要: true

开拓星神阿基维利与无名客乘星穹列车穿越诸界，以星轨连接不同文明。阿基维利陨落后，旧有开拓网络逐渐受损。

姬子后来修复列车，与帕姆及新一代乘员重新启程。列车沿阿基维利遗留的航路旅行，并逐步承担处理星核阻塞与援助沿途世界的任务。

## 卡芙卡与星核猎手的剧本

- 时代: 星核时代
- 日期: 约主线开始前
- 章节: 序章
- 次要: false

艾利欧以「剧本」安排星核猎手介入黑塔空间站，卡芙卡、银狼负责其中的关键步骤。计划围绕星核、开拓者的载体及其之后的选择展开。

这一阶段的行动直接促成开拓者加入列车，但艾利欧所预见的完整未来及剧本最终目的仍未公开。

## 开拓者被植入星核

- 时代: 开拓之旅
- 日期: 1.0
- 章节: 序章
- 次要: false

卡芙卡与银狼借黑塔空间站防务出现空隙，将封存的星核植入载体，使开拓者苏醒。开拓者仅保留零碎记忆，对自己的过去和星核本质均缺乏认识。

三月七与丹恒随后发现开拓者，三人一同应对紧随而至的空间站危机。

## 黑塔空间站遇袭与末日兽

- 时代: 开拓之旅
- 日期: 1.0
- 章节: 序章
- 次要: false

反物质军团袭击黑塔空间站，列车组协助站内人员撤离并抵御入侵。末日兽随后现身，开拓者体内的星核在战斗中失控，并受到毁灭星神纳努克的瞥视。

瓦尔特制止了进一步的暴走。危机暂解后，开拓者接受姬子的邀请登上星穹列车，正式加入新的开拓旅程。

## 抵达雅利洛-VI

- 时代: 开拓之旅
- 日期: 1.0
- 章节: 雅利洛-VI
- 次要: false

为修复被星核阻塞的航线，列车组抵达雅利洛-VI。开拓者、三月七与丹恒在雪原遇见桑博，随后进入贝洛伯格并觐见大守护者可可利亚。

可可利亚将列车组列为通缉对象，布洛妮娅起初奉命追捕。众人转入下层区后，开始追查寒潮、裂界与星核之间的联系。

## 上下层区与史瓦罗

- 时代: 开拓之旅
- 日期: 1.0
- 章节: 雅利洛-VI
- 次要: false

下层区长期与上层隔绝，由「地火」等力量维持基本秩序。列车组与希儿、娜塔莎合作，并在机械聚落接触史瓦罗与克拉拉。

史瓦罗依据自身计算拒绝提供星核情报，双方在冲突后终于取得其保存的历史资料。这些记录帮助众人理解星核与寒潮的真相，也促成布洛妮娅重新审视母亲的决策。

## 可可利亚与星核决战

- 时代: 开拓之旅
- 日期: 1.0
- 章节: 雅利洛-VI
- 次要: false

布洛妮娅选择相信列车组，与众人返回上层区并前往永冬岭。可可利亚在星核影响下动用其力量，与列车组及布洛妮娅决战，最终战败身亡。

列车组随后封印星核，贝洛伯格的危机暂告结束。寒潮和裂界造成的损害并未立刻消失，城市仍需长期恢复。

## 布洛妮娅继位

- 时代: 开拓之旅
- 日期: 1.0
- 章节: 雅利洛-VI
- 次要: false

可可利亚死后，布洛妮娅继任大守护者，上层区与下层区重新建立往来。她对外将可可利亚描述为抵御灾难而牺牲，没有公布其受星核支配的全部细节，以维持社会对守护者制度的信任。

布洛妮娅着手推动两区和解与重建，贝洛伯格由此进入新的治理阶段。

## 抵达仙舟罗浮

- 时代: 开拓之旅
- 日期: 1.0
- 章节: 仙舟·罗浮
- 次要: false

列车组循卡芙卡提供的信息前往仙舟「罗浮」。卡芙卡主动接受太卜司控制，引导列车组留在罗浮协助处理危机；将军景元则借外部力量调查星核与内部叛乱。

刃的出现迫使丹恒直面饮月君的过去，星核猎手的剧本、罗浮的内乱和列车组的行动由此交汇。

## 建木重生与药王秘传

- 时代: 开拓之旅
- 日期: 1.0—1.2
- 章节: 仙舟·罗浮
- 次要: false

罗浮内部的星核危机引发建木复生，药王秘传也借丹鼎司等渠道扩大行动。该组织以丰饶信仰号召追随者，试图改变仙舟对长生与丰饶灾祸的现行立场。

列车组与罗浮各方合作，揭露药王秘传首领丹枢及其实验，并逐步确认幻胧才是推动建木与星核危机的关键敌人。

## 饮月现世与幻胧之战

- 时代: 开拓之旅
- 日期: 1.2
- 章节: 仙舟·罗浮
- 次要: false

丹恒在刃的逼迫下显现饮月形态，被迫承接丹枫遗留的力量与旧业，同时坚持以今生身份作出选择。众人随后进入鳞渊境，直面借建木塑造躯壳的绝灭大君幻胧。

景元、饮月与列车组合力击败幻胧，建木危机暂时平息。罗浮虽免受毁灭，丹恒与故友之间的旧怨及持明族内部问题却未因此全部消解。

## 抵达匹诺康尼谐乐大典

- 时代: 开拓之旅
- 日期: 2.0
- 章节: 匹诺康尼
- 次要: false

星穹列车应家族邀请前往匹诺康尼参加谐乐大典。开拓者一行入住白日梦酒店，并进入由忆质构成的梦境，在那里与黄泉、黑天鹅、砂金、流萤等人产生交集。

梦中的死亡事件、各方对钟表匠遗产的争夺以及家族内部的矛盾接连浮现。盛会由此转为对匹诺康尼历史与梦境真相的调查。

## 太一之梦与星期日之战

- 时代: 开拓之旅
- 日期: 2.2
- 章节: 匹诺康尼
- 次要: false

星期日借谐乐大典与「秩序」的力量展开太一之梦，试图让众人留在由自己安排的安稳梦境中。其计划以消除现实痛苦为目标，却剥夺了人们清醒和选择的权利。

列车组与各方盟友逐步唤醒梦境中的人们，并在知更鸟等人的协助下击败神主日。匹诺康尼脱离太一之梦，家族也须面对事件留下的信任与权力问题。

## 抵达翁法罗斯与逐火之旅

- 时代: 开拓之旅
- 日期: 3.x
- 章节: 翁法罗斯
- 次要: false

开拓者与丹恒抵达长期封闭的翁法罗斯，在圣城奥赫玛接触阿格莱雅等黄金裔，并参与逐火之旅。众人的首要目标是回收泰坦火种，应对黑潮与失序泰坦带来的危机。

随着逐火预言推进，黄金裔各自的使命与代价逐渐显现，翁法罗斯同三重命途及外界的关系也逐步揭开。
