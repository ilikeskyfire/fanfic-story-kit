# 绝区零 时间线

## 旧都陷落

- 时代: 旧都时代
- 日期: 约 11 年前
- 章节: 背景
- 次要: false

旧都艾利都在一场空前的大规模空洞灾害中毁灭。防卫军、财阀与市政系统在灾难中各自逃生，大量平民被放弃。

这场灾难的真相被层层掩盖：有证据表明，当时被要求「死守铁路干线、掩护市民撤离」的部队，实际护送的是一列满载辉磁的货车。奥波勒斯小队与伊瑟尔德大佐的调查，正是从这条线索开始。

旧都陷落也是卡洛蕾·阿尔娜失踪、叶释渊与云岿山一系列事件的远因。

## 新艾利都建立

- 时代: 灾后重建
- 日期: 约 11 年前至今
- 章节: 背景
- 次要: false

幸存者在旧都废墟之外建立新艾利都，以辉磁与罗塞塔数据重建能源和信息体系。城市被空洞包围，形成「市区—外环—空洞」三层结构。

TOPS 及其加盟企业在新秩序中迅速做大，防卫军与市政厅相互牵制，绳匠与帮派填补了官方力量触及不到的缝隙。

## 辉晶美克扩张

- 时代: 灾后重建
- 日期: 约 10 年前起
- 章节: 背景
- 次要: true

辉晶美克在拉玛尼亚空洞大规模开采辉磁，成为 TOPS 体系内的重要企业。共同 CEO 卢克罗与菲洛克斯长期内斗，达米安·布莱克伍德在两人之间维持平衡。

企业对工人侵蚀事故的隐瞒，为第二季的冲突埋下伏笔。

## Random Play 录像店

- 时代: 第一季前
- 日期: 主线开始前
- 章节: 背景
- 次要: true

哲与铃兄妹在六分街经营录像店「Random Play」，暗中以「绳匠」身份接单。两人失去了部分过去，邦布「阿全」是他们最重要的伙伴。

## 序章「生意×诡异×道义」

- 时代: 第一季
- 日期: 版本 1.0
- 章节: 序章
- 次要: false

绳匠兄妹接到狡兔屋的委托，进入空洞带路。妮可的「生意」从一开始就充满了意外：委托目标、赤牙帮与空洞中的异常同时爆发。

主角与狡兔屋建立起长期合作关系，也第一次正面接触赤牙帮与空洞灾害的残酷。

## 第二季开幕「云霞同归处」

- 时代: 第二季

## 第二季第二章「迟吟的浪涌」

- 时代: 第二季
- 日期: 版本 2.1
- 章节: 第二季第二章
- 次要: false

安全调查晚宴开场，辉晶美克共同 CEO 卢克罗与菲洛克斯的内斗公开化。爱丽丝·泰姆菲尔德以调查监督身份介入，露西、狛野真斗、浮波柚叶、黎宝荣等卫非地人物登场。

辉晶美克的「新叶计划」人体实验被揭露，ES-07 即柚叶。菲洛克斯与讃颂会勾结，仪玄击败米亚兹马·菲恩德，爱丽丝以无偿转让专利换取达米安放行。事件后，爱丽丝、柚叶、真斗在网络论坛「怪啖屋」集结。

伊瑟尔德最终选择死在鬼火刀下，弥留之际，米亚兹马映出卡洛蕾·阿尔娜的幻影。莎拉继承「司教」权能，叶释渊随她离开适当观。
